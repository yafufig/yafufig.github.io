# Dmitrii Iarochkin - portfolio

Public professional portfolio at https://yafufig.github.io/.

Static HTML, CSS and JavaScript. Hosted with GitHub Pages from the main branch.

The site presents selected work from the owner-provided CVs. No private employment code, datasets, phone number or resume PDFs are published. Public project links point to the owner’s existing repositories.

To preview locally: `python3 -m http.server 8765`.
